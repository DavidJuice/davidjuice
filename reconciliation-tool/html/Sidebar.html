Plog Sync

Configuration pending.

This tool reads scheduled emails from AgencyBloc (sent to a Workspace mailbox) and appends new events to the Plog tracking Sheet.

Before it can run, the admin needs to:

  1. Set up the AgencyBloc scheduled email reports.
  2. Confirm the Plog Sheet column schema.
  3. Provide the mapping from AB field changes to event types (newborn / onboard / switch / renewal / cancel / transfer).

Once configured, install the schedule from the Apps Script editor: installPlogSync().
